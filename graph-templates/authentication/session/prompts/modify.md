The renderer never overwrites custom code. To change timeouts, re-render with new `idleTimeout`/`absoluteTimeout` inputs only on an unmodified install, or set `SESSION_IDLE_TIMEOUT_SECONDS`/`SESSION_ABSOLUTE_TIMEOUT_SECONDS` at runtime. To use Redis or another shared store, implement `SessionStore` (get/set/destroy/touch/destroyAllForUser, `productionReady: true`), set `SESSION_STORE=custom`, and call `configureSessionStore()` before the server accepts requests. Protect application routes with `requireSession` and, for state-changing methods, `csrfProtection`; call `regenerateSession()` after any privilege change the role check cannot see, and `revokeUserSessions()` after a password change.
